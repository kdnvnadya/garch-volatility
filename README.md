# Анализ волатильности S&P 500 и Bitcoin с помощью GARCH-моделей

Пет-проект по эконометрике: сравниваю поведение волатильности классического индекса акций (S&P 500) и криптовалюты (Bitcoin), строю и тестирую GARCH-модели, считаю VaR и смотрю, насколько сильно связаны доходности этих двух активов.

## Идея

Биткоин часто называют "цифровым золотом" с непредсказуемой волатильностью, а S&P 500 — эталоном "спокойного" рынка. Хотелось проверить это на данных: правда ли волатильность BTC настолько отличается по структуре, какая модель GARCH лучше описывает каждый из активов, и есть ли между ними корреляция (то есть насколько крипта реально независима от традиционного рынка).

## Данные

- Источник: Yahoo Finance (`yfinance`)
- Тикеры: `BTC-USD`, `^GSPC`
- Период: 2018-01-01 — 2025-12-31
- Используются логарифмические доходности, выборка разбита на train/test в пропорции 80/20 (без перемешивания, просто по времени)

## Что сделано

1. **Разведочный анализ** — описательные статистики доходностей, тест ADF на стационарность, тест Жарка-Бера на нормальность.
2. **ARCH-эффект** — тест Энгла (het_arch) на обеих сериях, чтобы обосновать применимость GARCH.
3. **Подбор спецификации** — сравнение GARCH(1,1), GARCH(1,2), GARCH(2,1) и GJR-GARCH(1,1) по AIC/BIC отдельно для BTC и S&P 500 (у активов может быть разная лучшая модель — например, ассиметричная реакция на плохие новости у индекса лучше ловится GJR-GARCH).
4. **Диагностика остатков** — тест Льюнга-Бокса на автокорреляцию (в т.ч. квадратов остатков), повторный ARCH-тест, JB-тест на нормальность стандартизированных остатков.
5. **Прогноз волатильности** — rolling one-step-ahead прогноз на тестовой выборке (модель переобучается на расширяющемся окне), сравнение с фактической волатильностью через RMSE и QLIKE.
6. **Value at Risk** — расчёт условного VaR на 95% и 99% на основе подобранных GARCH-моделей (t-распределение остатков).
7. **Корреляция** — корреляция доходностей BTC и S&P 500 (весь период / train / test), а также скользящая корреляция с окном 90 дней.

## Стек

Python, `yfinance`, `pandas`, `numpy`, `scipy`, `statsmodels`, `arch`, `matplotlib`.

## Как запустить

Открыть `.ipynb` в Jupyter/Colab и выполнить ячейки по порядку. Первая ячейка сама ставит пакет `arch`, если его нет.

```bash
pip install yfinance pandas numpy scipy statsmodels arch matplotlib
```

Требуется интернет для загрузки котировок через `yfinance`.

## Что можно делать дальше

- Добавить DCC-GARCH для явного моделирования динамической корреляции вместо скользящего окна
- Многомерный GARCH (BEKK) — динамическая ковариационная матрица для риска портфеля из нескольких активов
- Copula-модели — раздельное моделирование маржинальных распределений и tail dependence между BTC и акциями
- Regime-switching / Markov-switching GARCH — волатильность крипты скачет между режимами, обычный GARCH это сглаживает
- Полноценный backtesting VaR: тесты Kupiec (unconditional coverage) и Christoffersen (independence, conditional coverage) на скользящем окне, а не только in-sample
- Expected Shortfall (CVaR) вместо/вместе с VaR
- EVT / Peaks-over-Threshold для хвостов распределения остатков
- Стресс-тестирование и сценарный анализ (исторические кризисы, гипотетические шоки)
- HAR-RV на внутридневных данных как альтернатива GARCH, если найти источник минутных/часовых котировок
- Сравнение с ML-подходами (LSTM/GRU, gradient boosting на признаках волатильности) как бенчмарк против GARCH
- Попробовать другие распределения остатков (skew-t) для GJR-GARCH
- Обернуть пайплайн в переиспользуемый модуль: загрузка данных → подбор модели → расчёт VaR/ES → отчёт, с конфигом на новые тикеры без переписывания кода
- Простой risk-dashboard (обновление данных, пересчёт VaR, алерты при пробое лимитов)
- Автоматизированный backtesting-фреймворк, прогоняющий несколько моделей и метрик разом по единому протоколу
- Добавить другие активы (золото, другие индексы, другие крупные криптовалюты) — расширить до мультиактивного риск-фреймворка
- Учесть структурные события (одобрение BTC ETF, халвинги, решения ФРС по ставке) через dummy-переменные или тесты на структурные сдвиги
